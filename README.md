# UG CHAT

UG CHAT is a simple school chatroom web application built with **HTML, CSS, and JavaScript**.  
It features multiple chat feeds, a premium profile system, and a mobile-friendly layout.

## Features
- Live chatroom UI (localStorage-based)
- Mobile-first responsive design
- Progressive Web App (PWA) support (with manifest & service worker)
- Simple and lightweight — no backend required

## Deployment
This project is designed to be hosted on **GitHub Pages**.  
Once deployed, it can be accessed at:  
`https://your-username.github.io/ug-chat/`
